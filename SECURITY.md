# Security

Report vulnerabilities to **security@agentbadge.xyz**.

Please include: affected version (`release-manifest.json` → `version`),
protocol artifact if relevant (job/capability id), reproduction steps.
We aim to acknowledge within 3 business days.

Do NOT report via public GitHub issues or wp.org forums — the pull
protocol's capability whitelist is security-sensitive by design
(ADR-INTEL-002).
